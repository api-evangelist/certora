# Certora

> Certora is a smart-contract security company. Its core product, the Certora Prover, performs automated formal verification of smart contracts on EVM chains, Solana, Stellar (Soroban), and Sui, checking every reachable state and path for critical vulnerabilities. Developers write rules in the Certora Verification Language (CVL) and run verification jobs against Certora's cloud with the open-source certora-cli (certoraRun) tool.

## Products
- [Certora Prover](https://www.certora.com/prover): Automated formal-verification engine for smart contracts.
- [Gambit](https://www.certora.com/): Mutation-testing tool for evaluating CVL specs.
- [Audits](https://www.certora.com/audits): Expert manual smart-contract security audits.
